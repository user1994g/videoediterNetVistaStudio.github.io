# NetVista Studio 1.4 Beta 4

A major creative-tools beta, with the largest additions in the native macOS app.

## macOS

- Studio Home with separate editor windows and recent projects.
- Layered photo editing, blank documents, painting and erasing, brush controls, supported ABR brush import, selections, masks, adjustments, and editable photo projects.
- Expanded colour grading with wheels, curves, qualifiers, scopes, grade nodes, and custom cube LUT export.
- Improved 3D scene editing, object manipulation, rigging and animation controls.
- Game Maker for empty 2D/3D projects, imported assets, visual logic, native play preview, and Three.js/Python source export.
- Improved local-network sharing and account sign-in.
- In-place update installation with project recovery and rollback support for compatible future releases.

## Windows and Linux

- Updated native Qt editor packages with account sign-in and periodic account verification.
- Existing timeline, export, and package-update workflows remain available. The macOS Photo Editor, Game Maker, and advanced 3D features are not ported to these editions.

## Beta limitations

- Back up projects before using this beta. Features remain experimental.
- The macOS download is Apple Silicon, ad-hoc signed, and not Apple-notarized; Gatekeeper may block its first launch.
- Windows/Linux downloads must be extracted as complete folders.
- Game character and sprite-sheet animations currently preview natively but are not supported in source exports.
- In-place updating is macOS-only. End-to-end updating on a separate test Mac has not been verified for this release.

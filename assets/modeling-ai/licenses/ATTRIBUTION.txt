NetVista modifications are provided in netvista-completion.patch:
1. Generated completion token pieces go directly to stdout so --log-disable
   suppresses diagnostics/EOS decorations without suppressing the JSON result.
2. Global/user config.ini loading is disabled for the app-owned helper.
The parent uses fixed local-file arguments and --offline. Server, subprocess,
OpenSSL, GPU, dynamic backends and OpenMP support are not built. No C++ source
or code produced by the model is executed. The executable is signed with the app.

The model is unmodified data; NetVista changes only the bounded planning prompt.

This is a small structured planning assistant, not a trained text-to-mesh model.
It can suggest native modeling actions for the user to review and apply. It does
not create production-quality topology, remesh arbitrary shapes or replace Blender.
